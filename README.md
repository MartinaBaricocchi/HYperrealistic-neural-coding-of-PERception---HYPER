# Phosphene-Vision-1
I carried out this assignment within the course AI for Neurotechnology by professor Yağmur Güçlütürk, followed at Radboud University. 
This assignment was completed in collaboration with one other student. 
I explored how generative adversarial networks (GANs) can be combined with fMRI data to investigate neural encoding and decoding of face perception. I trained machine learning models to predict brain responses to generated faces and reconstruct faces from brain activity, using Python, neural data analysis, and visualization techniques.
